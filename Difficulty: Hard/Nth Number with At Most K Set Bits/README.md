<h2><a href="https://www.geeksforgeeks.org/problems/geekina-hate-1s/1">Nth Number with At Most K Set Bits</a></h2><h3>Difficulty Level : Difficulty: Hard</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Given two integers <strong>n</strong> and <strong>k</strong>, find the n<sup>th</sup> non-negative integer whose binary representation contains at most k set bits (1s). The numbers are considered in increasing order starting from 0.&nbsp;</span></p>
<p><span style="font-size: 18.6667px;"><strong>Note:</strong> It is guaranteed that the answer exists and fits in a signed 64-bit integer.</span></p>

<pre><span style="font-size: 14pt;"><strong>Input: </strong>n = 6, k = 2</span><br><span style="font-size: 14pt;"><strong>Output: </strong>5</span><br><span style="font-size: 14pt;"><strong>Explanation: </strong></span><span style="font-size: 14pt;">The non-negative integers whose binary representation contains at most 2 set bits, in increasing order, are:<br>0 = (0)<sub>2</sub><br>1 = (1)<sub>2</sub><br>2 = (10)<sub>2</sub><br><span style="font-size: 14pt;">3 = (11)<sub>2</sub><br>4 = (100)<sub>2</sub><br>5 = (101)</span><sub style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;"><span style="font-family: -apple-system, BlinkMacSystemFont, Segoe UI, Roboto, Oxygen, Ubuntu, Cantarell, Open Sans, Helvetica Neue, sans-serif;"><span style="font-size: 14pt;">2<br>The 6th number in this sequence is 5.</span></span></sub></span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Binary Search</code>&nbsp;<code>Bit Magic</code>&nbsp;
